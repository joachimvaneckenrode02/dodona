# H4 - Spaarbedrag berekenen - basis

Je spaart elke week hetzelfde bedrag.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var bedragPerWeek = 5;
var aantalWeken = 4;
```

## Verwerking

Gebruik een `for`-lus om het totale spaarbedrag week per week op te bouwen.

## Exacte uitvoer

Print exact één zin:

```text
Na 4 weken heb je 20 euro gespaard.
```
