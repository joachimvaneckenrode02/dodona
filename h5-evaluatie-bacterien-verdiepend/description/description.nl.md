# Evaluatie H5 - Bacteriën verdubbelen - verdiepend

Een bacteriecultuur groeit snel.

Na elke ronde verdubbelt het aantal bacteriën.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var aantalBacterien = 6;
var grens = 200;
```

## Verwerking

Gebruik een `while`-lus om te berekenen hoeveel rondes nodig zijn tot het aantal bacteriën minstens gelijk is aan de grens.

Gebruik daarna een selectie om de groei te beoordelen:

- minder dan 5 rondes: `snelle groei`
- van 5 tot en met 7 rondes: `normale groei`
- meer dan 7 rondes: `trage groei`

## Exacte uitvoer

Print exact twee zinnen:

```text
Na 6 rondes zijn er 384 bacteriën.
Dit is een normale groei.
```
