# Evaluatie H5 v2 - Rente laten groeien - verdiepend

Een spaarbedrag groeit elk jaar met een vaste rente.

Na elk jaar komt er een vast percentage bij.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var bedrag = 500;
var doel = 650;
var rente = 0.08;
```

## Verwerking

Gebruik een `while`-lus om te berekenen na hoeveel jaren het bedrag minstens gelijk is aan het doel.

Zolang het bedrag kleiner is dan het doel, komt er rente bij.

Gebruik `bedrag.toFixed(2)` om het bedrag met 2 cijfers na de komma te tonen.

Gebruik daarna een selectie om de wachttijd te beoordelen:

- minder dan 4 jaar: `korte wachttijd`
- van 4 tot en met 6 jaar: `normale wachttijd`
- meer dan 6 jaar: `lange wachttijd`

## Exacte uitvoer

Print exact twee zinnen:

```text
Na 4 jaren is het bedrag 680.24 euro.
Dit is een normale wachttijd.
```
