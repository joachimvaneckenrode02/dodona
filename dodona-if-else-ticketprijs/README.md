# Dodona-oefening: Ticketprijs met if, else if en else

Deze map bevat een volledige Dodona-oefening voor JavaScript.

## Structuur

- `config.json`: instellingen voor Dodona
- `description/description.nl.md`: opgave voor de leerling
- `evaluation/suite.yaml`: automatische testen voor Dodona TESTed
- `solution/solution.js`: modeloplossing

## Thema

De oefening traint:

- `if`
- `else if`
- `else`
- vergelijken met `<` en `<=`
- uitvoer met `console.log()`

## Opmerking

De startcode gebruikt deze regel om invoer te lezen in Dodona:

```javascript
var input = require("fs").readFileSync(0, "utf8").trim();
```

Daarna kunnen leerlingen gewoon werken met `var`, vergelijkingen en `console.log()`.
