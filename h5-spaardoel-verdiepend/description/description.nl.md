# H5 - Spaardoel bereiken - verdiepend

Je spaart voor een nieuwe fiets.

Je start met een bepaald bedrag.
Elke week spaar je een vast bedrag bij.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var startBedrag = 35;
var spaarbedragPerWeek = 18;
var doel = 120;
```

## Verwerking

Gebruik een `while`-lus om te berekenen hoeveel weken je moet sparen om het doel te bereiken.

Zolang het totale bedrag kleiner is dan het doel, spaar je één week verder.

Gebruik daarna een selectie om de spaartijd te beoordelen:

- minder dan 5 weken: `snel gehaald`
- van 5 tot en met 8 weken: `haalbaar`
- meer dan 8 weken: `lang sparen`

## Exacte uitvoer

Print exact twee zinnen:

```text
Na 5 weken heb je 125 euro.
Dit spaardoel is haalbaar.
```
