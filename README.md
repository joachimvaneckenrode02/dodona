# Dodona expert-oefeningen wiskundig inzicht

Deze zip bevat twee uploadklare Dodona-oefeningen:

- perfect-getal-expert
- vriendengetallen-expert

Elke oefening gebruikt deze structuur:

- config.json
- description/description.nl.md
- evaluation/suite.yaml
- solution/solution.js

De oefeningen gebruiken TESTed als judge en JavaScript als programmeertaal.
Elke stdin/stdout-testcase staat in een aparte context.
