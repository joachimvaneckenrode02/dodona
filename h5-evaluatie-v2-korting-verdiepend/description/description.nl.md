# Evaluatie H5 v2 - Kortingsbonnen gebruiken - verdiepend

Een leerling koopt een duur toestel.

Hij gebruikt telkens een kortingsbon met een vast bedrag.
Hij blijft kortingsbonnen gebruiken tot de prijs laag genoeg is.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var prijs = 275;
var doelPrijs = 180;
var kortingPerBon = 22;
```

## Verwerking

Gebruik een `while`-lus om te berekenen hoeveel kortingsbonnen nodig zijn.

Zolang de prijs groter is dan de doelprijs, wordt er één kortingsbon gebruikt.

Gebruik daarna een selectie om het aantal kortingsbonnen te beoordelen:

- minder dan 4 bonnen: `weinig bonnen`
- van 4 tot en met 6 bonnen: `normaal aantal bonnen`
- meer dan 6 bonnen: `veel bonnen`

## Exacte uitvoer

Print exact twee zinnen:

```text
Na 5 bonnen is de prijs 165 euro.
Dit is een normaal aantal bonnen.
```
