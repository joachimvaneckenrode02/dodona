# H5 - Waterbak vullen - basis

Een waterbak wordt gevuld met emmers water.

Elke emmer bevat evenveel liter water.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var inhoud = 0;
var doel = 30;
var literPerEmmer = 7;
```

## Verwerking

Gebruik een `while`-lus om te berekenen hoeveel emmers nodig zijn.

Zolang de inhoud kleiner is dan het doel, voeg je één emmer water toe.

## Exacte uitvoer

Print exact één zin:

```text
Na 5 emmers zit er 35 liter in de waterbak.
```
