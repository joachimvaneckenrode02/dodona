# Evaluatie H5 v2 - Pagina's lezen - basis

Een leerling leest elke dag hetzelfde aantal pagina's.

Hij stopt wanneer hij het boek uit heeft.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var gelezenPaginas = 0;
var totaalPaginas = 95;
var paginasPerDag = 12;
```

## Verwerking

Gebruik een `while`-lus om te berekenen hoeveel dagen de leerling moet lezen.

Zolang het aantal gelezen pagina's kleiner is dan het totaal, leest de leerling een nieuwe dag.

## Exacte uitvoer

Print exact één zin:

```text
Na 8 dagen heeft de leerling 96 pagina's gelezen.
```
