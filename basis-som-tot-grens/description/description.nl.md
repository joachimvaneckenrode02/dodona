# Som tot aan de grens

Je krijgt een positief geheel getal als grens.

Tel met een `while`-lus alle getallen vanaf 1 op, zolang de som kleiner is dan de grens.

Toon daarna:

1. hoeveel getallen je hebt opgeteld;
2. wat de som is;
3. of de som precies gelijk is aan de grens of niet.

## Invoer

Eén positief geheel getal.

## Uitvoer

Drie regels:

```text
Aantal: ...
Som: ...
...
```

De derde regel is `Precies gelijk` of `Niet precies gelijk`.
