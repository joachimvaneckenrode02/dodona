# Evaluatie H5 v2 - Bus vullen - basis

Een bus wordt gevuld met leerlingen.

Bij elke halte stappen er evenveel leerlingen op.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var aantalLeerlingen = 0;
var doel = 38;
var leerlingenPerHalte = 9;
```

## Verwerking

Gebruik een `while`-lus om te berekenen hoeveel haltes nodig zijn.

Zolang het aantal leerlingen kleiner is dan het doel, stappen er leerlingen op.

## Exacte uitvoer

Print exact één zin:

```text
Na 5 haltes zitten er 45 leerlingen in de bus.
```
