# Evaluatie H4 - Driehoeksgetal - verdiepend

Een driehoeksgetal krijg je door de getallen van 1 tot en met een gekozen getal op te tellen.

Bijvoorbeeld: bij 4 hoort `1 + 2 + 3 + 4 = 10`.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabele in je code:

```javascript
var aantal = 12;
```

## Verwerking

Gebruik een `for`-lus om het driehoeksgetal te berekenen.

Gebruik daarna een selectie om het resultaat te beoordelen:

- minder dan 50: `klein driehoeksgetal`
- van 50 tot en met 100: `middelgroot driehoeksgetal`
- meer dan 100: `groot driehoeksgetal`

## Exacte uitvoer

Print exact twee zinnen:

```text
Het driehoeksgetal van 12 is 78.
Dit is een middelgroot driehoeksgetal.
```
