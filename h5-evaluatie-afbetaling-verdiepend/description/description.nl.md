# Evaluatie H5 - Afbetaling volgen - verdiepend

Een leerling koopt een laptop op afbetaling.

Elke maand betaalt hij een vast bedrag terug.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var schuld = 340;
var betalingPerMaand = 55;
```

## Verwerking

Gebruik een `while`-lus om te berekenen na hoeveel maanden de schuld volledig afbetaald is.

Zolang de schuld groter is dan 0, wordt er één maand betaald.

Gebruik daarna een selectie om de afbetaling te beoordelen:

- minder dan 6 maanden: `korte afbetaling`
- van 6 tot en met 10 maanden: `normale afbetaling`
- meer dan 10 maanden: `lange afbetaling`

## Exacte uitvoer

Print exact twee zinnen:

```text
Na 7 maanden is de schuld afbetaald.
De laatste stand is -45 euro. Dit is een normale afbetaling.
```
