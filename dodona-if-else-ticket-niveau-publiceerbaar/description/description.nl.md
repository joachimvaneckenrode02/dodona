# Ticket kiezen met `if`, `else if` en `else`

## Gegeven

In een pretpark bestaan er verschillende soorten tickets.
Het soort ticket hangt af van de leeftijd.

Voor deze oefening gebruiken we deze leeftijd:

```javascript
var leeftijd = 14;
```

## Gevraagd

Schrijf een programma dat bepaalt welk ticket iemand krijgt.

Gebruik deze regels:

- jonger dan 6 jaar: `gratis toegang`
- van 6 tot en met 11 jaar: `kinderticket`
- van 12 tot en met 17 jaar: `jongerenticket`
- vanaf 18 jaar: `volwassenenticket`

Bewaar het juiste ticket in de variabele `ticket`.

De uitvoer moet exact deze zin zijn:

```text
Je krijgt een jongerenticket.
```

var ticket = "";
