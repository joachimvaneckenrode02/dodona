# Evaluatie H4 v2 - Boeken op een plank - basis

Een boekenkast heeft meerdere planken.

Op elke plank staan evenveel boeken.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var boekenPerPlank = 9;
var aantalPlanken = 6;
```

## Verwerking

Gebruik een `for`-lus om het totale aantal boeken te berekenen.

## Exacte uitvoer

Print exact één zin:

```text
In de kast staan 54 boeken.
```
