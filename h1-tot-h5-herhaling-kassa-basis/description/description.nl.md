# Herhaling H1-H5 - Kassa leegrekenen - basis

Een leerling koopt meerdere broodjes.

Hij heeft een vast budget.
Elk broodje kost evenveel euro.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var budget = 30;
var prijsBroodje = 4;
```

## Verwerking

Gebruik een `while`-lus om te berekenen hoeveel broodjes de leerling kan kopen.

Zolang er genoeg budget is voor nog één broodje, koopt de leerling een broodje.

## Exacte uitvoer

Print exact twee zinnen:

```text
De leerling koopt 7 broodjes.
Er blijft 2 euro over.
```
