# Evaluatie H4 - Stappen tellen - basis

Een leerling telt een week lang zijn stappen.

Elke dag zet hij evenveel stappen.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var stappenPerDag = 6500;
var aantalDagen = 7;
```

## Verwerking

Gebruik een `for`-lus om het totale aantal stappen te berekenen.

## Exacte uitvoer

Print exact één zin:

```text
Na 7 dagen heeft de leerling 45500 stappen gezet.
```
