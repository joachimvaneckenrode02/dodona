# Evaluatie H4 v2 - Tafelpunten berekenen - verdiepend

Een leerling oefent de maaltafel van een getal.

Voor elke uitkomst krijgt de leerling evenveel punten als de uitkomst zelf.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var tafel = 4;
var aantalOefeningen = 8;
```

## Verwerking

Gebruik een `for`-lus om de som van de uitkomsten te berekenen.

Bereken dus:

```text
4 + 8 + 12 + 16 + 20 + 24 + 28 + 32
```

Gebruik daarna een selectie:

- minder dan 100 punten: `lage score`
- van 100 tot en met 180 punten: `goede score`
- meer dan 180 punten: `hoge score`

## Exacte uitvoer

Print exact twee zinnen:

```text
De leerling behaalt 144 punten.
Dit is een goede score.
```
