# Ticket kiezen met if, else if en else

## Gegeven

Een pretpark gebruikt verschillende soorten tickets.

De leeftijd bepaalt welk ticket iemand krijgt.

- Jonger dan 6 jaar: `gratis ticket`
- Van 6 tot en met 11 jaar: `kinderticket`
- Van 12 tot en met 17 jaar: `jongerenticket`
- Vanaf 18 jaar: `volwassenenticket`

## Gevraagd

Schrijf een programma dat bepaalt welk ticket nodig is.

Gebruik deze waarden:

```javascript
var leeftijd = 14;
var ticket = "";
```

Gebruik `if`, `else if` en `else`.

Zorg dat de uitvoer exact gelijk is aan het voorbeeld hieronder.

## Verwachte uitvoer

```text
Je krijgt een jongerenticket.
```
