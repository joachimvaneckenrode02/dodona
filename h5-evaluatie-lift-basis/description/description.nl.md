# Evaluatie H5 - Lift naar boven - basis

Een lift vertrekt op een bepaalde verdieping.

De lift gaat telkens hetzelfde aantal verdiepingen omhoog.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var huidigeVerdieping = 0;
var doelVerdieping = 17;
var stap = 4;
```

## Verwerking

Gebruik een `while`-lus om te berekenen hoeveel keer de lift moet bewegen.

Zolang de lift lager staat dan de doelverdieping, gaat de lift één stap omhoog.

## Exacte uitvoer

Print exact één zin:

```text
Na 5 bewegingen staat de lift op verdieping 20.
```
