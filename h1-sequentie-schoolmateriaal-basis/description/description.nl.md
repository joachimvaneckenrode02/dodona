# H1 - Sequentie - Schoolmateriaal - basis

Je koopt schoolmateriaal voor een leerling.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Invoer

De gebruiker geeft zes waarden in.

Eerst geef je de naam van de leerling in.

Daarna geef je het aantal schriften in.

Daarna geef je de prijs van 1 schrift in.

Daarna geef je het aantal potloden in.

Daarna geef je hoeveel potloden er in 1 doos zitten.

Daarna geef je de prijs van 1 doos potloden in.

## Verwerking

Bereken de totale kostprijs van de schriften.

Bereken hoeveel volledige dozen potloden je moet kopen.

Bereken hoeveel potloden er over zijn.

Bereken de kostprijs van de dozen potloden.

Bereken het totaalbedrag.

Rond geldbedragen af op 2 cijfers na de komma.

## Exacte uitvoer

Bij de invoer:

```text
Noor
4
2.75
23
10
1.80
```

verschijnt:

```text
Bestelling voor Noor.
De schriften kosten 11.0 euro.
Je koopt 3 dozen potloden.
Er zijn 7 potloden over.
De potloden kosten 5.4 euro.
In totaal betaal je 16.4 euro.
```
