# Herhaling H1-H5 - Bloementuin vullen - verdiepend

Een tuinier plant bloemen in rijen.

De eerste rij heeft een vast aantal bloemen.
Elke volgende rij heeft meer bloemen dan de vorige rij.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var bloemenEersteRij = 4;
var extraPerRij = 3;
var aantalRijen = 6;
```

## Verwerking

Gebruik een `for`-lus om het totale aantal bloemen te berekenen.

Bereken per rij hoeveel bloemen er in die rij staan.
Tel dit aantal telkens op bij het totaal.

Gebruik daarna een selectie om de tuin te beoordelen:

- minder dan 60 bloemen: `kleine bloementuin`
- van 60 tot en met 100 bloemen: `middelgrote bloementuin`
- meer dan 100 bloemen: `grote bloementuin`

## Exacte uitvoer

Print exact twee zinnen:

```text
De tuinier plant 69 bloemen.
Dit is een middelgrote bloementuin.
```
