# Evaluatie H5 - Kassa bijhouden - basis

Een leerling verkoopt drankjes op een activiteit.

Elk drankje kost evenveel euro.
De leerling blijft verkopen tot er genoeg geld in de kassa zit.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var bedragInKassa = 12;
var doelBedrag = 45;
var prijsPerDrankje = 4;
```

## Verwerking

Gebruik een `while`-lus om te berekenen hoeveel drankjes nog verkocht moeten worden.

Zolang het bedrag in de kassa kleiner is dan het doelbedrag, wordt er één drankje verkocht.

## Exacte uitvoer

Print exact één zin:

```text
Er moeten nog 9 drankjes verkocht worden.
```
