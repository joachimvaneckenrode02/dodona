# Bevriende getallenparen

Gebruik Papyros via <https://papyros.dodona.be/>.

Twee verschillende getallen zijn bevriend als de som van de echte delers van het eerste getal gelijk is aan het tweede getal, en omgekeerd.

Voorbeeld: `220` en `284` zijn bevriend.

## Gegeven variabele

Gebruik deze variabele:

```javascript
var grens = 300;
```

## Verwerking

Onderzoek alle getallen van `2` tot en met `grens`.

Bereken voor elk getal de som van zijn echte delers.

Zoek alle bevriende paren waarbij beide getallen kleiner dan of gelijk aan `grens` zijn.

Print elk paar één keer.

Print daarna ook hoeveel bevriende paren je vond.

## Exacte uitvoer

```text
220 en 284
aantal: 1
```
