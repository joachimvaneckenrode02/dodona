# Evaluatie H4 - Rechthoeken stapelen - verdiepend

Je stapelt rechthoeken met blokjes.

De eerste rechthoek heeft breedte 2.
Elke volgende rechthoek is 1 blokje breder.
De hoogte blijft altijd gelijk.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var startBreedte = 2;
var hoogte = 4;
var aantalRechthoeken = 5;
```

## Verwerking

Gebruik een `for`-lus om het totale aantal blokjes te berekenen.

Bereken voor elke rechthoek eerst de oppervlakte.
Tel die oppervlakte op bij het totaal.

Gebruik daarna een selectie om het bouwwerk te beoordelen:

- minder dan 70 blokjes: `klein bouwwerk`
- van 70 tot en met 120 blokjes: `middelgroot bouwwerk`
- meer dan 120 blokjes: `groot bouwwerk`

## Exacte uitvoer

Print exact twee zinnen:

```text
Voor 5 rechthoeken heb je 80 blokjes nodig.
Dit is een middelgroot bouwwerk.
```
