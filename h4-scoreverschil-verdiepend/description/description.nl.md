# Evaluatie H4 v2 - Scoreverschil optellen - verdiepend

Een ploeg speelt meerdere wedstrijden.

Ze scoort elke wedstrijd evenveel punten.
De tegenstander scoort ook elke wedstrijd evenveel punten.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var eigenScorePerWedstrijd = 18;
var tegenScorePerWedstrijd = 13;
var aantalWedstrijden = 6;
```

## Verwerking

Gebruik een `for`-lus om het totale scoreverschil te berekenen.

Bereken per wedstrijd eerst het verschil.
Tel dit verschil telkens op bij het totale verschil.

Gebruik daarna een selectie:

- verschil kleiner dan 20: `klein verschil`
- verschil van 20 tot en met 40: `duidelijk verschil`
- verschil groter dan 40: `groot verschil`

## Exacte uitvoer

Print exact twee zinnen:

```text
Na 6 wedstrijden is het totale scoreverschil 30 punten.
Dit is een duidelijk verschil.
```
