# H4 - Stickerboek vullen - basis

Je vult een stickerboek.

Elke dag plak je evenveel stickers in het boek.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var stickersPerDag = 6;
var aantalDagen = 5;
```

## Verwerking

Gebruik een `for`-lus om het totale aantal geplakte stickers te berekenen.

## Exacte uitvoer

Print exact één zin:

```text
Na 5 dagen heb je 30 stickers geplakt.
```
