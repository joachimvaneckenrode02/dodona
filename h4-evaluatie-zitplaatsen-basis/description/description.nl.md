# Evaluatie H4 - Zitplaatsen tellen - basis

In een zaal staan verschillende rijen stoelen.

Elke rij heeft evenveel zitplaatsen.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var aantalRijen = 12;
var stoelenPerRij = 8;
```

## Verwerking

Gebruik een `for`-lus om het totale aantal zitplaatsen te berekenen.

Gebruik daarna een selectie om de zaal te beoordelen:

- minder dan 80 plaatsen: `kleine zaal`
- van 80 tot en met 120 plaatsen: `middelgrote zaal`
- meer dan 120 plaatsen: `grote zaal`

## Exacte uitvoer

Print exact twee zinnen:

```text
De zaal heeft 96 zitplaatsen.
Dit is een middelgrote zaal.
```
