# Perfecte getallen zoeken

Gebruik Papyros via <https://papyros.dodona.be/>.

Een getal is perfect als de som van zijn echte delers gelijk is aan het getal zelf.

Voorbeeld: `6` is perfect, want `1 + 2 + 3 = 6`.

## Gegeven variabele

Gebruik deze variabele:

```javascript
var grens = 30;
```

## Verwerking

Onderzoek alle getallen van `1` tot en met `grens`.

Bereken voor elk getal de som van zijn echte delers.

Print elk perfect getal op een aparte regel.

Print daarna ook hoeveel perfecte getallen je vond.

## Exacte uitvoer

```text
6
28
aantal: 2
```
