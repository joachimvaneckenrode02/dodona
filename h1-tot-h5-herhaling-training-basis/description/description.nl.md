# Herhaling H1-H5 - Training optellen - basis

Een leerling traint meerdere dagen.

Elke dag traint hij evenveel minuten.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var minutenPerDag = 25;
var aantalDagen = 6;
```

## Verwerking

Gebruik een `for`-lus om het totale aantal trainingsminuten te berekenen.

Gebruik daarna een selectie om de training te beoordelen:

- minder dan 120 minuten: `lichte training`
- van 120 tot en met 180 minuten: `goede training`
- meer dan 180 minuten: `zware training`

## Exacte uitvoer

Print exact twee zinnen:

```text
De leerling traint 150 minuten.
Dit is een goede training.
```
