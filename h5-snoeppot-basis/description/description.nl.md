# H5 - Snoeppot leegmaken - basis

Er zitten snoepjes in een pot.

Elke dag worden er enkele snoepjes opgegeten.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var aantalSnoepjes = 24;
var snoepjesPerDag = 5;
```

## Verwerking

Gebruik een `while`-lus om te berekenen na hoeveel dagen de pot leeg is.

Zolang er nog snoepjes in de pot zitten, gaat er een nieuwe dag voorbij.
Op elke dag worden er `snoepjesPerDag` snoepjes opgegeten.

## Exacte uitvoer

Print exact één zin:

```text
Na 5 dagen is de snoeppot leeg.
```
