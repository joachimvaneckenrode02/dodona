# H5 - Filmavond plannen - verdiepend

Een groep leerlingen plant een filmavond.

Ze hebben een budget voor drankjes en snacks.
Elke leerling kost hetzelfde bedrag.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var budget = 50;
var kostPerLeerling = 6;
```

## Verwerking

Gebruik een `while`-lus om te berekenen hoeveel leerlingen kunnen deelnemen.

Zolang er genoeg budget is voor nog één leerling, voeg je één leerling toe.

Gebruik daarna een selectie om de groep te beoordelen:

- minder dan 6 leerlingen: `kleine groep`
- van 6 tot en met 10 leerlingen: `normale groep`
- meer dan 10 leerlingen: `grote groep`

## Exacte uitvoer

Print exact twee zinnen:

```text
Er kunnen 8 leerlingen deelnemen.
Er blijft 2 euro over. Dit is een normale groep.
```
