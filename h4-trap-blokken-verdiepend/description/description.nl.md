# H4 - Trap van blokken - verdiepend

Een bouwer maakt een trap met blokken.

Rij 1 heeft 1 blok.
Rij 2 heeft 2 blokken.
Rij 3 heeft 3 blokken.
En zo gaat het verder.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabele in je code:

```javascript
var aantalRijen = 5;
```

## Verwerking

Gebruik een `for`-lus om het totale aantal blokken te berekenen.

Gebruik daarna een selectie om de trap te beoordelen:

- minder dan 15 blokken: `kleine trap`
- van 15 tot en met 50 blokken: `middelgrote trap`
- meer dan 50 blokken: `grote trap`

## Exacte uitvoer

Print exact twee zinnen:

```text
Voor 5 rijen heb je 15 blokken nodig.
Dit is een middelgrote trap.
```
