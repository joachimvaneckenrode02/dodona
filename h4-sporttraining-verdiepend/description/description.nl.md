# H4 - Sporttraining opbouwen - verdiepend

Een leerling bouwt zijn looptraining op.

Op de eerste dag loopt hij een vast aantal minuten.
Elke volgende dag loopt hij enkele minuten meer.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var startMinuten = 10;
var extraPerDag = 3;
var aantalDagen = 6;
```

## Verwerking

Gebruik een `for`-lus om het totale aantal loopminuten te berekenen.

Dag 1 telt `startMinuten` minuten.
Elke volgende dag komt er `extraPerDag` minuten bij.

Gebruik daarna een selectie om de training te beoordelen:

- minder dan 100 minuten: `lichte training`
- van 100 tot en met 150 minuten: `stevige training`
- meer dan 150 minuten: `zware training`

## Exacte uitvoer

Print exact twee zinnen:

```text
In 6 dagen loopt de leerling 105 minuten.
Dit is een stevige training.
```
