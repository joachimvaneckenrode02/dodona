# H4 - Parkeerplaatsen tellen - basis

Een parking heeft meerdere rijen.

Elke rij heeft evenveel parkeerplaatsen.

Je test je code eerst in [Papyros](https://papyros.dodona.be/).

## Opgegeven variabelen

Gebruik deze variabelen in je code:

```javascript
var plaatsenPerRij = 14;
var aantalRijen = 8;
```

## Verwerking

Gebruik een `for`-lus om het totale aantal parkeerplaatsen te berekenen.

## Exacte uitvoer

Print exact één zin:

```text
De parking heeft 112 parkeerplaatsen.
```
