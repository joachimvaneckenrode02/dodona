# Dodona-oefening: Toegangsniveau bepalen

Deze oefening is bedoeld voor beginnende leerlingen JavaScript.

Leerdoel:

- werken met `var`
- werken met `if`
- werken met `else if`
- werken met `else`
- uitvoer tonen met `console.log()`

De leerling werkt met een vaste variabele:

```javascript
var leeftijd = 14;
```

Er wordt geen invoer via `require("fs")` gebruikt.
