# Toegangsniveau bepalen

## Gegeven

Een sportcentrum werkt met vier toegangsniveaus.

De leeftijd bepaalt welk toegangsniveau iemand krijgt.

- Jonger dan 6 jaar: `gratis toegang`
- Van 6 tot en met 11 jaar: `kinderticket`
- Van 12 tot en met 17 jaar: `jongerenticket`
- Vanaf 18 jaar: `volwassenenticket`

## Gevraagd

Schrijf een programma dat:

- een variabele `leeftijd` maakt;
- een variabele `ticket` maakt;
- met `if`, `else if` en `else` controleert welk ticket nodig is;
- deze zin exact afdrukt:

```text
Je krijgt een jongerenticket.
```

Gebruik in je code deze leeftijd:

```javascript
var leeftijd = 14;
```

## Startcode

```javascript
var leeftijd = 14;
var ticket = "";

// Schrijf hieronder je code
```

## Verwachte uitvoer

```text
Je krijgt een jongerenticket.
```

Maak gebruik van de Papyros-omgeving om jouw code uit te testen en te debuggen. Dien daarna jouw code in via de Dodona-omgeving.
